Features

Built for developers who ship

GitHub Auto-Sync

Connect once, update forever. READMEs, stars, releases, commits—all synced automatically. Zero maintenance.

Mention Tracking

We crawl HackerNews, Reddit, Product Hunt, Twitter, and blogs. Like Google Scholar citations, but for your code.

Embeddable Widgets

One script tag. That's it. The widget inherits your site's CSS variables—fonts, colors, spacing. Native, not embedded.

Dev Profiles

Your work deserves better than a GitHub profile. Get a polished page at launchlog.com/yourname with all your projects.

Getting started

Setup in 60 seconds

setup.ts
// Step 1: Sign in with GitHub
const user = await launchlog.auth('github');

// Step 2: We sync your repos automatically
const repos = await user.sync(); // 12 repos synced

// Step 3: Share your profile
const profile = user.getProfileUrl();
// → "launchlog.com/yourname"

// Bonus: Embed on your site
const widget = '<script src="launchlog.com/embed/you.js"></script>';
