Implementation Notes

  • All API calls should show loading spinners immediately on button click
  • Success states show briefly (1.5s) before redirecting to dashboard
  • Error states persist until user takes action (retry or dismiss)
  • Use toast notifications for non-blocking feedback
  • Full-page overlays for critical blocking states (initial save)
  • Preserve selected repos in local state during error recovery
  • Implement optimistic UI where appropriate (toggling repos)
  • Add analytics events at each major flow transition
