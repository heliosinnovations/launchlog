CSS Variable Inheritance

Widgets automatically inherit your site's design system via CSS variables. Override any variable to match your brand.

/* Your site's CSS - widgets will inherit these */ :root { --ll-font-family: 'Your Font', sans-serif; --ll-color-bg: #1E1B4B; --ll-color-surface: #312E81; --ll-color-text: #E0E7FF; --ll-color-text-secondary: #A5B4FC; --ll-color-border: #4338CA; --ll-color-primary: #818CF8; --ll-radius-sm: 8px; --ll-radius-md: 12px; } /* Embed the widget */ <script src="https://launchlog.com/widget.js" data-user="sarahguo" data-style="compact"></script>
