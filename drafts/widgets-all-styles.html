Theme Customization

Override CSS variables to match your site's design system.

/* Override LaunchLog widget theme */
:root {
--ll-bg: #your-background;
--ll-bg-hover: #your-hover-bg;
--ll-border: #your-border-color;
--ll-text: #your-text-color;
--ll-text-muted: #your-muted-text;
--ll-primary: #your-brand-color;
--ll-radius: 8px;
}
